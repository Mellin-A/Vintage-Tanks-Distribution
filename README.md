# Vintage Tanks Launcher

Для Windows x64 доступна предварительная сборка 4.4 preview.2. В ней работает очередь оригинального конструктора, шкалы реализации и резервная загрузка файлов через EU или RU через EU. [Скачать preview.2](https://github.com/Mellin-A/Vintage-Tanks-Distribution/releases/download/launcher-4.4-preview.2/VintageTanksLauncher-4.4-Windows-x64.zip) · [Все выпуски лаунчера](https://github.com/Mellin-A/Vintage-Tanks-Distribution/releases)

Здесь лаунчер получает файлы библиотеки и интеграции с проектом. В каталоге выпуска указаны путь, размер и SHA-256 каждого архива. Лаунчер скачивает конкретную ревизию GitHub и проверяет контрольную сумму до установки.

В архиве `packages/launcher-4.4.zip` находятся 30 004 компонента конструктора 4.4. Авторские демонстрационные пакеты включают описания, справочные данные, условные схемы, прицел и синтезированный звуковой пример. Для входа через Vintage Tanks включён обработчик оригинальной формы 0.7.0. Для запуска игры пользователь выбирает свою локальную установку World of Tanks соответствующей версии.
